#🏦 City Bank – C++ Banking System

About the Project

City Bank is a simple command-line banking system developed using C++. The project was created as part of the Introduction to Programming (NQF Level 4) assignment at Gauteng City College.

The program allows users to log into their bank accounts and perform basic banking transactions through a menu-driven system.

Features

The banking system includes the following features:

- User Login: Users log in using their account number and PIN.
- Deposit: Allows users to deposit money into their accounts.
- Withdraw: Allows users to withdraw money, provided they have sufficient funds.
- Send Cash: Allows users to transfer money to another registered account.
- Check Balance: Displays the user's current account balance.
- Input Validation: Prevents invalid transactions and incorrect menu selections.
- Multiple Users: Supports three registered bank users.

How to Run the Program

1. Download or clone this repository.
2. Open the C++ source code in a C++ compiler or IDE.
3. Compile and run the program.
4. Log in using one of the provided test accounts.
5. Select an option from the banking menu to perform a transaction.

Banking Menu

The program provides five main options:

1. Deposit
2. Withdraw
3. Send Cash
4. Check Balance
5. Exit
